# SauceDemo Manual QA Testing

## About This Project

This is a manual QA testing project I created while practicing software testing.

I tested the SauceDemo website to practice creating test cases, finding bugs, and documenting test results.

## What I Tested

* Login
* Product inventory
* Product sorting
* Product details
* Shopping cart
* Checkout
* Order completion
* Logout
* Reset App State
* Mobile responsiveness

## Testing Documentation

* Test Plan
* Test Cases
* Bug Reports
* Test Execution
* Test Summary

## Bugs Found

* **B-001:** Checkout allows users to complete an order with an empty cart
* **B-002:** Checkout Overview does not display the customer's entered information
