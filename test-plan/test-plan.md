# SauceDemo Manual QA Test Plan

## 1. Objective

The objective of this test is to verify that the main features of the SauceDemo web application work as expected and to identify defects that may affect the user experience or application functionality.

## 2. Scope

The testing will cover the following features:

* Login
* Product inventory
* Product sorting
* Product details
* Shopping cart
* Checkout
* Order completion
* Logout
* Reset App State
* Mobile responsiveness

## 3. Testing Approach

The following testing approaches will be used:

* Functional Testing
* Exploratory Testing
* Positive Testing
* Negative Testing
* UI/Usability Testing
* Compatibility Testing

## 4. Test Environment

* **Operating System:** Windows 10
* **Browser:** Brave v1.95.101
* **Application:** SauceDemo web application

## 5. Test Data

The following test account will be used:

* **Username:** standard_user
* **Password:** secret_sauce

Additional test data will be created when testing checkout fields, product selection, and other application features.

## 6. Entry Criteria

Testing can begin when:

* The SauceDemo website is accessible.
* A valid test account is available.
* The test environment is ready.

## 7. Exit Criteria

Testing will be considered complete when:

* The planned features have been tested.
* Test cases have been executed.
* Identified defects have been documented.
* Test results have been recorded.
* A test summary has been prepared.

## 8. Deliverables

The following documents will be produced:

* Test Cases
* Bug Reports
* Test Execution Results
* Test Summary

## 9. Out of Scope

The following are not included in this project:

* Source code testing
* Backend infrastructure testing
* Real payment processing
* Production environment testing
* Security penetration testing
